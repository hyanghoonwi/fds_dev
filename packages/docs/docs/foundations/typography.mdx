# Typography

Pretendard 기반 Text Style입니다. `text-title-1`, `text-body-1`처럼 Tailwind 유틸리티로 사용합니다. 글자 크기, 굵기, 행간, 자간이 한 클래스에 함께 들어 있습니다.

:::note[`cn()`과 함께 쓸 때]
core의 `cn()`(`clsx` + `tailwind-merge`)은 이 `text-*` 토큰 이름을 **글자 크기**로 등록해 두었습니다. 그래서 `cn("text-caption-2", "text-text-caption")`처럼 글자 색 클래스와 함께 써도 글자 크기가 지워지지 않습니다. 토큰을 새로 추가하면 `packages/core/src/utils/cn.ts`의 목록에도 추가해야 합니다.
:::
