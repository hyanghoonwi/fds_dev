# Badge

짧은 상태나 개수를 표시하는 작은 라벨입니다.

## Usage

<Preview>
  <Badge>NEW</Badge>
  <Badge>12</Badge>
  <Badge>공지</Badge>
</Preview>

```tsx
<Badge>NEW</Badge>
<Badge>12</Badge>
<Badge>공지</Badge>
```

## Props

| Prop        | 타입                   | 기본값 | 설명                                  |
| ----------- | ---------------------- | ------ | ------------------------------------- |
| `children`  | `ReactNode`            | -      | **필수.** 라벨 내용                   |
| `className` | `string`               | -      | 추가 클래스 (`tailwind-merge`로 병합) |
| `ref`       | `Ref<HTMLSpanElement>` | -      | React 19 `ref` prop                   |

나머지 `<span>` 속성은 그대로 전달됩니다. variant나 size는 없고 단일 스타일입니다.
