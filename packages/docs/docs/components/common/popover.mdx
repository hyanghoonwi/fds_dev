# Popover

기준 요소(anchor) 가까이에 뜨는 범용 오버레이입니다. 날짜나 시간 같은 도메인은 모릅니다. 입력창이나 버튼을 트리거로 두고, 그 아래(또는 위)에 원하는 내용을 띄웁니다. [DatePicker](./date-picker), [TimePicker](./time-picker), Select가 모두 이 위에 만들어져 있습니다.

## Usage

`trigger`로 열고 닫는 요소를, `children`으로 팝업 내용을 넘깁니다. 열림 상태나 닫기 함수가 필요하면 둘 다 **함수로** 넘기면 받을 수 있습니다.

export function BasicDemo() {
  return (
    <Popover
      label="더보기 메뉴"
      containerClassName="w-fit"
      trigger={({ open, toggle, anchorRef }) => (
        <Button
          ref={anchorRef}
          variant="line"
          onClick={toggle}
          aria-haspopup="dialog"
          aria-expanded={open}
        >
          더보기
        </Button>
      )}
    >
      {({ close }) => (
        <div
          style={{
            display: "flex",
            flexDirection: "column",
            gap: 8,
            width: 160,
          }}
        >
          <Button variant="line" onClick={close}>
            방송 공유
          </Button>
          <Button variant="line" onClick={close}>
            링크 복사
          </Button>
          <Button variant="danger" onClick={close}>
            신고하기
          </Button>
        </div>
      )}
    </Popover>
  );
}

- 버튼 트리거에서는 `anchorRef`를 버튼의 `ref`에 넘깁니다. 팝업이 그 버튼의 왼쪽 아래에 붙습니다.
- 컨테이너 기본값은 `w-full`입니다. 버튼처럼 내용 폭만 차지하게 하려면 `containerClassName="w-fit"`을 줍니다.
- 바깥을 누르거나 `Esc`를 누르면 닫힙니다. `Esc`로 닫으면 포커스가 트리거로 돌아갑니다.

## Input에 꽂아 쓰기

날짜 선택기를 새 컴포넌트로 감싸지 않아도, **기존 `Input`에 `Calendar`를 꽂아서** 같은 결과를 얻을 수 있습니다. 세 가지만 하면 됩니다.

1. `trigger`에 `Input`을 넣습니다. 읽기 전용으로 두고 클릭하면 `toggle`을 부릅니다.
2. `Input`의 `fieldRef`에 `anchorRef`를 넘깁니다. 팝업이 라벨이나 에러 문구 아래가 아니라 **입력 박스 바로 아래**에 붙습니다.
3. `children`에 `Calendar`를 넣고, 날짜를 고르면 값을 저장한 뒤 `close()`를 부릅니다.

export function InputDemo() {
  const [date, setDate] = useState(null);
  return (
    <div style={{ width: 320 }}>
      <Popover
        label="날짜 선택"
        trigger={({ open, toggle, anchorRef }) => (
          <Input
            readOnly
            label="시작일"
            placeholder="날짜 선택"
            value={date ?? ""}
            fieldRef={anchorRef}
            onClick={toggle}
            aria-haspopup="dialog"
            aria-expanded={open}
            rightAddon={<CalendarIcon />}
          />
        )}
      >
        {({ close }) => (
          <Calendar
            autoFocus
            value={date}
            onSelect={(next) => {
              setDate(next);
              close();
            }}
          />
        )}
      </Popover>
    </div>
  );
}

- `Calendar`는 이미 선택된 날짜를 다시 눌러도 닫히도록 `onChange`가 아니라 **`onSelect`**를 씁니다. `onChange`는 값이 바뀔 때만 호출됩니다.
- `DatePicker`는 이 조합을 미리 해 둔 편의 컴포넌트입니다. 폼에 날짜 필드가 여럿이면 `DatePicker`를 쓰고, 다른 트리거나 배치가 필요하면 이렇게 직접 조합하세요.
- `Input`의 다른 props(`label`, `required`, `error`, `name` 등)는 그대로 쓸 수 있습니다.

## 제어 모드

`open`과 `onOpenChange`를 넘기면 열림 상태를 바깥에서 제어합니다.

export function ControlledDemo() {
  const [open, setOpen] = useState(false);
  return (
    <div style={{ display: "flex", gap: 12, alignItems: "flex-start" }}>
      <Button variant="line" onClick={() => setOpen(true)}>
        열기
      </Button>
      <Button variant="line" onClick={() => setOpen(false)}>
        닫기
      </Button>
      <Popover
        label="제어 예"
        containerClassName="w-fit"
        open={open}
        onOpenChange={setOpen}
        trigger={
          <span style={{ fontSize: 14, lineHeight: "36px" }}>
            상태: {open ? "열림" : "닫힘"}
          </span>
        }
      >
        <div style={{ fontSize: 14 }}>바깥 버튼으로 열고 닫을 수 있어요.</div>
      </Popover>
    </div>
  );
}

## 위치

`placement`로 기준 요소에 대한 위치를, `offset`으로 간격을 정합니다.

| placement               | 위치                                        |
| ----------------------- | ------------------------------------------- |
| `bottom-start` (기본)   | 기준 요소 아래, **왼쪽** 가장자리에 맞춤    |
| `bottom-end`            | 기준 요소 아래, **오른쪽** 가장자리에 맞춤  |
| `top-start` / `top-end` | 기준 요소 위, 왼쪽 / 오른쪽 가장자리에 맞춤 |

```tsx
<Popover label="메뉴" placement="top-end" offset={12} trigger={...}>
  ...
</Popover>
```

## Props

| Prop                 | 타입                                                         | 기본값            | 설명                                                        |
| -------------------- | ------------------------------------------------------------ | ----------------- | ----------------------------------------------------------- |
| `trigger`            | `ReactNode \| (state: PopoverTriggerState) => ReactNode`     | -                 | 팝업을 여는 트리거. 열림 상태가 필요하면 함수로 넘김 (필수) |
| `children`           | `ReactNode \| (api: { close: () => void }) => ReactNode`     | -                 | 팝업 안의 내용. 닫기 함수가 필요하면 함수로 넘김 (필수)     |
| `label`              | `string`                                                     | -                 | 팝업의 접근성 이름(`aria-label`) (필수)                     |
| `open`               | `boolean`                                                    | -                 | 열림 여부(제어 모드)                                        |
| `defaultOpen`        | `boolean`                                                    | `false`           | 처음 열려 있을지(비제어 모드)                               |
| `onOpenChange`       | `(open: boolean) => void`                                    | -                 | 열림 상태가 바뀔 때 호출                                    |
| `role`               | `"dialog" \| "listbox" \| "menu"`                            | `"dialog"`        | 팝업의 ARIA 역할. 선택 목록은 `listbox`, 메뉴는 `menu`      |
| `busy`               | `boolean`                                                    | -                 | 팝업 내용을 불러오는 중이면 `aria-busy`가 붙음              |
| `placement`          | `"bottom-start" \| "bottom-end" \| "top-start" \| "top-end"` | `"bottom-start"`  | 기준 요소에 대한 팝업 위치                                  |
| `offset`             | `number`                                                     | `6`               | 기준 요소와 팝업 사이 간격(px)                              |
| `className`          | `string`                                                     | -                 | 팝업 패널의 클래스                                          |
| `containerClassName` | `string`                                                     | `relative w-full` | 트리거를 감싸는 컨테이너의 클래스                           |

### trigger 함수가 받는 값

| 이름        | 타입                       | 설명                                                                              |
| ----------- | -------------------------- | --------------------------------------------------------------------------------- |
| `open`      | `boolean`                  | 열림 여부                                                                         |
| `toggle`    | `() => void`               | 열려 있으면 닫고, 닫혀 있으면 엶                                                  |
| `setOpen`   | `(open: boolean) => void`  | 열림 상태를 직접 지정                                                             |
| `anchorRef` | `RefCallback<HTMLElement>` | 팝업을 붙일 기준 요소를 등록하는 ref. `Input`은 `fieldRef`에, 버튼은 `ref`에 넘김 |
| `popupId`   | `string`                   | 팝업 요소의 id. 트리거의 `aria-controls`에 사용                                   |

`anchorRef`를 등록하지 않으면 Popover 컨테이너 전체가 기준이 됩니다.

## 참고

- **`document.body` 포털을 쓰지 않습니다.** 팝업은 컨테이너 안(DOM)에 `position: absolute`로 그려집니다. 다크 모드 `data-theme`가 body가 아니라 래퍼 요소에 걸려 있어도 토큰이 그대로 내려오게 하려는 선택입니다. 그래서 **`overflow: hidden`인 조상 안에서는 팝업이 잘릴 수 있습니다.**
- **화면 가장자리 충돌 처리가 없습니다.** 팝업이 화면 밖으로 나가도 자동으로 위치를 바꾸지 않습니다. 필요하면 `placement`를 직접 정하세요.
- **Modal 안에서 쓸 수 있습니다.** `Esc`는 팝업만 닫고(바깥 Modal은 닫히지 않음), 한 번 더 누르면 Modal이 닫힙니다.
- `Esc`는 포커스가 Popover 컨테이너(트리거나 팝업) 안에 있을 때 처리됩니다.
- 팝업 위치는 기준 요소와 컨테이너 크기가 바뀔 때(에러 문구가 생기는 등) 다시 계산됩니다.
- 팝업은 열릴 때 내용만 그릴 뿐 포커스를 옮기지 않습니다. 내용 안에서 포커스를 받아야 하면(예: `Calendar`의 `autoFocus`) 내용 쪽에서 지정하세요.
