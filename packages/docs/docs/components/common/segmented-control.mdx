# SegmentedControl

여러 항목 중 하나를 고르는 탭형 컨트롤입니다. 채팅/공지처럼 같은 영역의 뷰를 전환할 때 사용합니다.

## Usage

export function Demo() {
  const [tab, setTab] = useState("chat");
  return (
    <div style={{ width: 313 }}>
      <SegmentedControl
        items={[
          { value: "chat", label: "채팅" },
          { value: "notice", label: "공지" },
        ]}
        value={tab}
        onChange={setTab}
      />
    </div>
  );
}

활성 항목 아래 thumb이 슬라이드하며 이동하고, 컨테이너 크기가 바뀌면 자동으로 다시 맞춰집니다.

## Page dots

활성 항목에 `dotsCount`를 주면 라벨 아래에 점이 표시됩니다. 공지가 여러 개일 때 현재 위치를 `activeDotIndex`로 강조합니다.

export function DotsDemo() {
  const [tab, setTab] = useState("notice");
  return (
    <div style={{ width: 313 }}>
      <SegmentedControl
        items={[
          { value: "chat", label: "채팅" },
          { value: "notice", label: "공지", dotsCount: 3, activeDotIndex: 1 },
        ]}
        value={tab}
        onChange={setTab}
      />
    </div>
  );
}

## Props

### SegmentedControl

| Prop        | 타입                      | 기본값 | 설명                                                         |
| ----------- | ------------------------- | ------ | ------------------------------------------------------------ |
| `items`     | `SegmentedControlItem[]`  | -      | 항목 목록 (필수)                                             |
| `value`     | `string`                  | -      | 활성 항목의 `value` (필수, controlled)                       |
| `onChange`  | `(value: string) => void` | -      | 항목 클릭 시 호출 (필수). 이미 활성인 항목을 눌러도 호출됨   |
| `onClick`   | `(value: string) => void` | -      | 항목 클릭 시 `onChange`보다 먼저 호출. 같은 탭 재클릭 감지용 |
| `className` | `string`                  | -      | 추가 클래스                                                  |
| `ref`       | `Ref<HTMLDivElement>`     | -      | React 19 `ref` prop                                          |

나머지 `<div>` 속성은 그대로 전달됩니다.

### SegmentedControlItem

| 필드             | 타입     | 기본값 | 설명                                      |
| ---------------- | -------- | ------ | ----------------------------------------- |
| `value`          | `string` | -      | 항목 식별 값                              |
| `label`          | `string` | -      | 표시 텍스트                               |
| `dotsCount`      | `number` | -      | 활성 상태일 때 라벨 아래에 표시할 점 개수 |
| `activeDotIndex` | `number` | -      | 점 중 강조할 인덱스                       |

## 참고

- 너비는 `w-full`이라 부모 너비를 따릅니다. Figma 기준 너비는 313px입니다.
- 항목은 균등 분할(`flex-1`)됩니다.
