# DatePicker

날짜 하나를 고르는 입력 필드입니다. 입력창이나 달력 아이콘을 누르면 아래에 달력이 열리고, 날짜를 고르면 `YYYY-MM-DD`로 표시되며 달력이 닫힙니다. 시간까지 고를 때는 [TimePicker](./time-picker)를 함께 사용하세요.

## Usage

`value`와 `onChange`로 제어하는 방식이 기본입니다. 달력은 입력창 아래로 열리므로, 아래 예제처럼 열릴 공간이 필요합니다.

export function Demo() {
  const [date, setDate] = useState(null);
  return (
    <div style={{ width: 280 }}>
      <DatePicker label="시작일" value={date} onChange={setDate} />
      <p
        style={{
          margin: "8px 0 0",
          fontSize: 12,
          color: "var(--fds-text-caption)",
        }}
      >
        선택한 날짜: {date ? date.toLocaleDateString("ko-KR") : "없음"}
      </p>
    </div>
  );
}

<Preview style={{ minHeight: 400, alignItems: "flex-start" }}>
  <Demo />
</Preview>

```tsx
import { useState } from "react";
import { DatePicker } from "@fds/core";

const [date, setDate] = useState<Date | null>(null);

<DatePicker label="시작일" value={date} onChange={setDate} />
```

초기값만 주고 상태를 직접 들고 있지 않으려면 `defaultValue`를 쓰세요(비제어).

```tsx
<DatePicker defaultValue={new Date(2026, 9, 6)} />
```

## 선택 가능한 범위

`min`, `max`로 범위를 제한하면 범위 밖의 날짜는 선택할 수 없고, 범위 밖으로 넘어가는 달 이동 버튼은 비활성화됩니다. 두 값 모두 포함(inclusive)입니다.

<Preview style={{ minHeight: 400, alignItems: "flex-start" }}>
  <div style={{ width: 280 }}>
    <DatePicker
      label="예약일"
      defaultValue={new Date(2026, 9, 15)}
      min={new Date(2026, 9, 10)}
      max={new Date(2026, 9, 25)}
    />
  </div>
</Preview>

```tsx
<DatePicker
  label="예약일"
  defaultValue={new Date(2026, 9, 15)}
  min={new Date(2026, 9, 10)}
  max={new Date(2026, 9, 25)}
/>
```

`isDateDisabled`는 날짜마다 호출되어 `true`를 반환하면 그 날짜를 막습니다. 주말이나 휴무일처럼 규칙으로 막을 때 사용합니다.

<Preview style={{ minHeight: 400, alignItems: "flex-start" }}>
  <div style={{ width: 280 }}>
    <DatePicker
      label="영업일"
      isDateDisabled={(date) => date.getDay() === 0 || date.getDay() === 6}
    />
  </div>
</Preview>

```tsx
<DatePicker
  label="영업일"
  isDateDisabled={(date) => date.getDay() === 0 || date.getDay() === 6}
/>
```

## 키보드

달력이 열리면 선택된 날짜(없으면 오늘)에 포커스가 가고, 아래 키로 이동합니다.

| 키                  | 동작                               |
| ------------------- | ---------------------------------- |
| `←` `→`             | 하루 전 / 하루 뒤                  |
| `↑` `↓`             | 일주일 전 / 일주일 뒤              |
| `Home` `End`        | 그 주의 일요일 / 토요일            |
| `PageUp` `PageDown` | 이전 달 / 다음 달                  |
| `Enter` `Space`     | 날짜 선택                          |
| `Esc`               | 달력 닫기 (입력창으로 포커스 복귀) |

## Props

`DatePicker`는 [Input](./input)의 props(`label`, `orientation`, `required`, `error`, `labelWidth`, `disabled`, `id`, `name`, `placeholder`, `className`, `containerClassName` 등)를 그대로 받습니다. 아래는 DatePicker에서 추가되거나 의미가 달라지는 props입니다.

| Prop             | 타입                           | 기본값        | 설명                                                        |
| ---------------- | ------------------------------ | ------------- | ----------------------------------------------------------- |
| `value`          | `Date \| null`                 | -             | 선택된 날짜(제어). `null`이면 선택 안 함                    |
| `defaultValue`   | `Date \| null`                 | `null`        | 초기 날짜(비제어)                                           |
| `onChange`       | `(date: Date \| null) => void` | -             | 날짜를 선택했을 때 호출. 로컬 시간 자정으로 정규화된 `Date` |
| `min`            | `Date`                         | -             | 선택 가능한 가장 이른 날짜(포함)                            |
| `max`            | `Date`                         | -             | 선택 가능한 가장 늦은 날짜(포함)                            |
| `isDateDisabled` | `(date: Date) => boolean`      | -             | `true`를 반환한 날짜는 선택 불가                            |
| `placeholder`    | `string`                       | `"날짜 선택"` | 값이 없을 때 표시할 문구                                    |
| `ref`            | `Ref<HTMLInputElement>`        | -             | React 19 `ref` prop (입력창에 연결)                         |

## 참고

- 표시 형식은 `YYYY-MM-DD`로 고정입니다. `name`을 주면 폼 전송 시 이 문자열이 전송됩니다.
- 입력창은 읽기 전용입니다. 날짜를 직접 타이핑하는 대신 달력에서 고릅니다.
- 날짜는 모두 로컬 시간 기준입니다. 이미 선택된 날짜를 다시 누르면 선택이 유지되고 `onChange`는 호출되지 않습니다.
- 현재 달이 아닌 날짜(앞뒤 회색 날짜)도 선택할 수 있고, 선택하면 그 달로 이동합니다.
- 달력은 입력창 바로 아래에 `position: absolute`로 열립니다. 부모에 `overflow: hidden`이 있으면 잘릴 수 있습니다.
- 달력은 한국어로 고정입니다(일 월 화 수 목 금 토, `2026년 10월`).
