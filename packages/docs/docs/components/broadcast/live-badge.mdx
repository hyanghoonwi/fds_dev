# LiveBadge

방송의 생방송 상태를 점과 텍스트로 알려주는 배지입니다. 영상 위에 얹어 쓰는 용도라 텍스트는 테마와 상관없이 항상 흰색입니다.

## Usage

export const videoBg = {
  background: "#242b35",
  padding: "12px 16px",
  borderRadius: 8,
};

<Preview>
  <div style={videoBg}>
    <LiveBadge />
  </div>
</Preview>

```tsx
<LiveBadge />
```

## Variants

`status`로 생방송(`live`)과 종료(`offline`) 상태를 구분합니다. `label`로 표시 문구를 바꿀 수 있습니다.

<Preview>
  <div style={videoBg}>
    <LiveBadge status="live" />
  </div>
  <div style={videoBg}>
    <LiveBadge status="offline" label="OFFLINE" />
  </div>
</Preview>

```tsx
<LiveBadge status="live" />
<LiveBadge status="offline" label="OFFLINE" />
```

## Props

| Prop        | 타입                   | 기본값   | 설명                                     |
| ----------- | ---------------------- | -------- | ---------------------------------------- |
| `status`    | `"live" \| "offline"`  | `"live"` | 점 색상. `live`는 빨강, `offline`은 회색 |
| `label`     | `string`               | `"LIVE"` | 표시 텍스트                              |
| `className` | `string`               | -        | 추가 클래스                              |
| `ref`       | `Ref<HTMLSpanElement>` | -        | React 19 `ref` prop                      |

## 참고

- 텍스트가 흰색 고정이므로 밝은 배경 위에서는 보이지 않습니다. 영상 같은 어두운 배경 위에 올려 사용하세요.
